Chapter 10: Syntax extensions

In this chapter, we introduce advanced commands to modify the way Coq parses and prints objects, i.e. the translations between the concrete and internal representations of terms and commands. The main commands are Notation and Infix.
Remark: : Commands Grammar, Syntax, Syntactic Definition and Distfix which were present for a while in Coq are no longer available from Coq version 8. The underlying AST structure is also no longer available.
