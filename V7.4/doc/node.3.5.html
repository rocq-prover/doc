Chapter 17: Proof of imperative programs

Jean-Christophe Filliâtre







Warning: The tactic presented in this chapter was a prototype implementation, now deprecated and no more maintained. It is subsumed by a much more powerful tool, developped and distributed independently of the system Coq, called Why (see http://why.lri.fr/).





This chapter describes a tactic to prove the correctness and termination of imperative programs annotated in a Floyd-Hoare logic style. The theoretical fundations of this tactic are described in [Filliatre99, Filliatre00a]. This tactic is provided in the Coq module Correctness, which does not belong to the initial state of Coq. So you must import it when necessary, with the following command:
Require Correctness.
