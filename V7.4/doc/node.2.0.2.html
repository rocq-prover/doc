10.3 Complex notations

Notation can be made from arbitraly complex symbols. One can for instance define prefix notations.

Coq < Notation "~ x" := (not x) (at level 5, right associativity).

One can also define notations for incomplete terms, with the hole expected to be inferred at typing time.

Coq < Notation "x = y" := (eq ? x y) (at level 5, no associativity).

One can define notations with parameters surrounded by symbols. In this case, the default precedence level for inner subexpression is 10.

Coq < Notation "{ A } + { B }" := (sumbool A B) (at level 1).

One can also define notations for binders.

Coq < Notation "{ x : A  |  P }" := (sig A [x:A]P) (at level 1).
