11.1 Syntax

The syntax of the tactic language is given in table 11.1. Terminal symbols are set in typewriter font (like this). Non-terminal symbols are set in italic font (like that). ... | ... denotes the or operation. entry ... entry denotes one or several repetitions of entry entry. entry sep ... sep entry denotes one or several repetitions separated by sep. The main entry is expr and the entries natural, integer, ident, qualid, term, pattern and primitive_tactic represent respectively the natural and integer numbers, the authorized identificators and qualified names, Coq's terms and patterns and all the basic tactics. In pattern, there can be specific variables like ?n where n is a natural or ?, which are metavariables for pattern matching. ?n allows us to keep instantiations and to make constraints whereas ? shows that we are not interested in what will be matched.

This language is used in proof mode but it can also be used in toplevel definitions as shown in table 11.2.
