Module Loadpath

* Load paths.

A load path is a physical path in the file system; to each load path is associated a Rocq DirPath.t (the "logical" path of the physical path).

Extending the Load Path
type vo_path = {
  1. unix_path : string;
    (*

    Filesystem path containing vo/ml files

    *)
  2. coq_path : Names.DirPath.t;
    (*

    Rocq prefix for the path

    *)
  3. implicit : bool;
    (*

    implicit = true avoids having to qualify with coq_path true for -R, false for -Q in command line

    *)
  4. recursive : bool;
    (*

    recursive will determine whether we explore sub-directories

    *)
  5. installed : bool;
    (*

    installed is true for automatically added paths (eg user-contrib), which are assumed to be installed files. False is assumed to be local files (ie current development).

    *)
}

Adds a path to the Rocq and ML paths
