Module Notation_term

notation_constr

notation_constr is the subtype of glob_constr allowed in syntactic extensions (i.e. notations). No location since intended to be substituted at any place of a text. Non global expressions such as existential variables are not allowed.

type notation_constr =
  1. | NRef of Names.GlobRef.t * Glob_term.glob_instance option
  2. | NVar of Names.Id.t
  3. | NApp of notation_constr * notation_constr list
  4. | NProj of Names.Constant.t * Glob_term.glob_instance option * notation_constr list * notation_constr
  5. | NHole of Glob_term.glob_evar_kind
  6. | NGenarg of GenConstr.glb
  7. | NList of Names.Id.t * Names.Id.t * notation_constr * notation_constr * bool
  8. | NLambda of Names.Name.t * notation_constr option * notation_constr
  9. | NProd of Names.Name.t * notation_constr option * notation_constr
  10. | NBinderList of Names.Id.t * Names.Id.t * notation_constr * notation_constr * bool
  11. | NLetIn of Names.Name.t * notation_constr * notation_constr option * notation_constr
  12. | NCases of Constr.case_style * notation_constr option * (notation_constr * (Names.Name.t * (Names.inductive * Names.Name.t list) option)) list * (Glob_term.cases_pattern list * notation_constr) list
  13. | NLetTuple of Names.Name.t list * Names.Name.t * notation_constr option * notation_constr * notation_constr
  14. | NIf of notation_constr * Names.Name.t * notation_constr option * notation_constr * notation_constr
  15. | NRec of Glob_term.glob_fix_kind * Names.Id.t array * (Names.Name.t * notation_constr option * notation_constr) list array * notation_constr array * notation_constr array
  16. | NSort of Glob_term.glob_sort
  17. | NCast of notation_constr * Constr.cast_kind option * notation_constr
  18. | NInt of Uint63.t
  19. | NFloat of Float64.t
  20. | NString of Pstring.t
  21. | NArray of notation_constr array * notation_constr * notation_constr

Note concerning NList: first constr is iterator, second is terminator; first id is where each argument of the list has to be substituted in iterator and snd id is alternative name just for printing; boolean is associativity

Type of variables when interpreting a constr_expr as a notation_constr: in a recursive pattern x..y, both x and y carry the individual type of each element of the list x..y

type notation_var_binders = Names.Id.Set.t

The set of other notation variables that are bound to a binder or binder list and that bind the given notation variable, for instance, in "{ x | P }" := (sigT (fun x => P), "x" is under an empty set of binders and "P" is under the binders bound to "x", that is, its notation_var_binders set is "x"

type 'a interpretation_gen = (Names.Id.t * 'a) list * notation_constr
