The Coq Proof Assistant

Changes from Coq V6.3 to Coq V6.3.1



This document describes the main differences between Coq V6.3 and V6.3.1. This new version of Coq is characterized by fixed bugs, and improvement of implicit arguments synthesis and speed in tactic applications.

1   Changes overview

1.1   Tactics

  • Tauto has been unable for a time to deal with hypotheses with 2 imbricated implications. Now it should work. Intuition now removes true, and therefore useless, hypotheses.
  • Several bugs of the Program are fixed (but some automatically generated names have changed and may lead to incompatibilities).

  • Bug with negative index in bindings fixed.

  • Speed improvement: redondant checks when applying a tactic have been turned off. For some tactics that don't make themselves the expected verifications, it may result in incorrect proofs detected only at Qed/Save time. In this last case, you can turn on the -tac-debug flag to coqtop.

  • The ``?'' in goals are now instantiated as soon as an instance is known for them.

1.2   Toplevel commands

Bug in Time fixed.

1.3   Language

Type reconstruction
The algorithm to solve incomplete information in terms has been improved furthermore. In particular question marks can be put in in place of the type of abstracted variables and in Cases expressions.

Guarded cofixpoints
A weakness in the guardness condition when a cofixpoint refers to another one has been corrected. WARNING: the new criterion may refuse some olderly accepted Cofixpoint definitions which actually are valid but for a reason difficult to detect automatically.

Extraction
A bug was limiting the number of propositional singleton inductive types (such has ``eq'') for which elimination towards Set is valid.

1.4   Incompatibilities

You could have to modify your vernacular source for the following reasons:

  • Some names of variables generated by the Program have changed.

  • Intuition now remove trye hypotheses.

  • In all cases, the ``.vo'' files are not compatible and should be recompiled.

3   Installation procedure

3.1   Uninstalling Coq

Warning
It is strongly recommended to clean-up the V6.3 Coq library directory before you install the new version. Use the option to coqtop -uninstall that will remove the binaries and the library files of Coq V6.3 on a Unix system.

3.2   OS Issues -- Requirements

3.2.1   Unix users

You need Objective Caml version 2.01 or later, and the corresponding Camlp4 version to compile the system. Both are available by anonymous ftp at:
ftp://ftp.inria.fr/Projects/Cristal.

Binary distributions are available for the following architectures:

OS Processor name of the package
Linux 80386 and higher coq-6.3.1-Linux-i386.tar.gz
Solaris Sparc coq-6.3.1-solaris-sparc.tar.gz
Digital Alpha coq-6.3.1-OSF1-alpha.tar.gz


There is also rpm packages for Linux.

If your configuration is in the above list, you don't need to install Caml and Camlp4 and to compile the system: just download the package and install the binaries in the right place.

3.2.2   MS Windows users

A binary distribution is available for PC under MS Windows 95/98/NT. The package is named coq-6.3.1-win.zip.

For installation information see the files INSTALL.win and README.win.
