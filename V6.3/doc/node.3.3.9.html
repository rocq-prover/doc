14.10 Examples

  • Coercion between inductive types

    Coq < Definition bool_in_nat := [b:bool]if b then O else (S O).
    bool_in_nat is defined

    Coq < Coercion bool_in_nat : bool >-> nat.
    bool_in_nat is now a coercion

    Coq < Check O=true.
    O=(true)
         : Prop


    Warning:
  • Check true=O. fails. This is ``normal'' behaviour of coercions. To validate true=O, the coercion is searched from nat to bool. There is no one.

  • Coercion to a sort

    Coq < Variable Graph : Type.
    Error during interpretation of command:
    Variable Graph : Type.
    Error: Clash with previous constant Graph

    Coq < Variable Node : Graph -> Type.
    Error during interpretation of command:
    Variable Node : Graph -> Type.
    Error: Clash with previous constant Node

    Coq < Coercion Node : Graph >-> SORTCLASS.
    Error during interpretation of command:
    Coercion Node : Graph >-> SORTCLASS.
    Error: Node is already a coercion

    Coq < Variable G : Graph.
    Error during interpretation of command:
    Variable G : Graph.
    Error: Clash with previous constant G

    Coq < Variable Arrows : G -> G -> Type.
    Error during interpretation of command:
    Variable Arrows : G -> G -> Type.
    Error: Clash with previous constant Arrows

    Coq < Check Arrows.
    Arrows
         : (G)->(G)->Type

    Coq < Variable fg : G -> G.
    Error during interpretation of command:
    Variable fg : G -> G.
    Error: Clash with previous constant fg

    Coq < Check fg.
    fg
         : (G)->(G)

  • Coercion to a function

    Coq < Variable bij : Set -> Set -> Set.
    Error during interpretation of command:
    Variable bij : Set -> Set -> Set.
    Error: Clash with previous constant bij

    Coq < Variable ap : (A,B:Set)(bij A B) -> A -> B.
    Error during interpretation of command:
    Variable ap : (A,B:Set)(bij A B) -> A -> B.
    Error: Clash with previous constant ap

    Coq < Coercion ap : bij >-> FUNCLASS.
    Error during interpretation of command:
    Coercion ap : bij >-> FUNCLASS.
    Error: ap is already a coercion

    Coq < Variable b : (bij nat nat).
    Error during interpretation of command:
    Variable b : (bij nat nat).
    Error: Clash with previous constant b

    Coq < Check (b O).
    (ap nat nat b O)
         : nat

  • Transitivity of coercion

    Coq < Variables C : nat -> Set; D : nat -> bool -> Set; E : bool -> Set.
    Error during interpretation of command:
    Variables C : nat -> Set; D : nat -> bool -> Set; E : bool -> Set.
    Error: Clash with previous constant C

    Coq < Variable f : (n:nat)(C n) -> (D (S n) true).
    Error during interpretation of command:
    Variable f : (n:nat)(C n) -> (D (S n) true).
    Error: Clash with previous constant f

    Coq < Coercion f : C >-> D.
    Error during interpretation of command:
    Coercion f : C >-> D.
    Error: f is already a coercion

    Coq < Variable g : (n:nat)(b:bool)(D n b) -> (E b).
    Error during interpretation of command:
    Variable g : (n:nat)(b:bool)(D n b) -> (E b).
    Error: Clash with previous constant g

    Coq < Coercion g : D >-> E.
    Error during interpretation of command:
    Coercion g : D >-> E.
    Error: g is already a coercion

    Coq < Variable c : (C O).
    Error during interpretation of command:
    Variable c : (C O).
    Error: Clash with previous constant c

    Coq < Variable T : (E true) -> nat.
    Error during interpretation of command:
    Variable T : (E true) -> nat.
    Error: Clash with previous constant T

    Coq < Check (T c).
    (T (c))
         : nat

  • Identity coercion

    Coq < Definition D' := [b:bool](D (S O) b).
    Error during interpretation of command:
    Definition D' := [b:bool](D (S O) b).
    Error: Clash with previous constant D'

    Coq < Identity Coercion IdD'D : D' >-> D.
    Error during interpretation of command:
    Identity Coercion IdD'D : D' >-> D.
    Error: Clash with previous constant IdD'D

    Coq < Print IdD'D.
    IdD'D = [b:bool; x:(D' b)]x
         : (b:bool)(D' b)->(D (S O) b)

    Coq < Variable d' : (D' true).
    Error during interpretation of command:
    Variable d' : (D' true).
    Error: Clash with previous constant d'

    Coq < Check (T d').
    (T (d'))
         : nat
